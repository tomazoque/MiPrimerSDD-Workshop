# Referencia de plantillas de Spec Kit

Esta carpeta contiene plantillas de Spec Kit para explorar los principales artefactos de un proceso de Spec-Driven Development (SDD).

## Plantillas disponibles

| Plantilla | Propósito general |
|---|---|
| `constitution-template.md` | Definir principios de programación y reglas del proyecto. |
| `spec-template.md` | Estructurar la especificación de requisitos. |
| `plan-template.md` | Organizar el plan de implementación y las decisiones técnicas. |
| `task-template.md` | Descomponer el trabajo en tareas. |
| `checklist-template.md` | Estructurar listas de comprobación. |

## Cómo utilizarlas en el taller

La plantilla de especificación es la referencia principal para la actividad de análisis de requisitos.

Las demás plantillas se incluyen para conocer los artefactos que pueden utilizarse en etapas posteriores del proceso SDD.

## Consideraciones

- Una plantilla ayuda a organizar el trabajo, pero no garantiza la calidad de su contenido.
- Las propuestas generadas por IA deben revisarse y justificarse.
- Las decisiones que dependen de información del usuario deben identificarse, no inventarse.
- Los artefactos y sus campos pueden cambiar según la versión de Spec Kit.
